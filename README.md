# Dream Sounds 🌙

تطبيق Android عربي لأصوات الطبيعة الحقيقية، مع مزج عدة أصوات، تحكم مستقل بمستوى الصوت، تشغيل في الخلفية، مؤقت نوم، وحفظ الخلطة.

## التسجيلات الحقيقية المتوفرة حالياً
1. **طيور الحديقة** — تسجيل ميداني لأصوات الطيور قبل المطر.
2. **النهر والضفادع** — تسجيل نهر صغير مع طيور وضفادع وحياة برية.
3. **رياح الحقول** — تسجيل ميداني للرياح في حقل مفتوح.

التسجيلات الثلاثة من حزمة **Park ambiences** للمؤلف Thimras على OpenGameArt، بترخيص CC0:
https://opengameart.org/content/park-ambiences

4. **أمواج الشاطئ** — تسجيل ميداني من ملف Beach Ocean Waves للمؤلف jasinski، بترخيص CC0:
https://opengameart.org/content/beach-ocean-waves

تُنزّل الملفات الأصلية عند أول تشغيل لكل صوت وتُخزّن داخل التطبيق، ثم يمكن تشغيلها دون إنترنت. ملفات WAV الأصلية الخاصة بالحديقة كبيرة نسبياً؛ يلزم اتصال إنترنت ومساحة تخزين كافية عند التنزيل الأول.

## الميزات
- مزج التسجيلات الأربعة في الوقت نفسه.
- مستوى صوت مستقل لكل تسجيل.
- تشغيل خلفي عبر Foreground Service.
- مؤقت نوم مع خفض تدريجي في آخر 30 ثانية.
- حفظ واستعادة آخر خلطة.
- جدولة تشغيل يومي.

## البناء
يتطلب JDK 17 وAndroid SDK 35:
`gradle --no-daemon assembleDebug`

## الشفافية
الأصوات المضافة هنا تسجيلات ميدانية وليست مؤثرات مولدة برمجياً. لم تُضف البومة وصراصير الليل والمطر والرعد بعد؛ لن تظهر في الواجهة حتى تتوفر ملفات أصلية مباشرة مع ترخيص إعادة توزيع واضح.
