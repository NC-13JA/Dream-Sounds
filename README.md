# Dream Sounds 🌙

تطبيق أندرويد لأصوات النوم والاسترخاء، بواجهة ليلية عربية ويعمل دون إنترنت بعد تثبيته.

## الميزات
- مزج المطر ونار المخيم والطيور والرياح والبحر والضوضاء البيضاء.
- مستوى صوت مستقل لكل صوت.
- تشغيل في الخلفية عبر خدمة تشغيل أمامية وإشعار.
- مؤقت نوم مع خفض تدريجي للصوت.
- حفظ واستعادة آخر خلطة.
- جدولة تشغيل صوت المطر يومياً في وقت يختاره المستخدم.

## البناء
افتح المستودع في Android Studio حديث مع JDK 17 وAndroid SDK 35، ثم نفّذ Build > Build APK(s). يتم إنشاء ملفات WAV محلياً تلقائياً أثناء Gradle build.

يمكن أيضاً تنزيل APK من تبويب Actions بعد نجاح سير العمل `Android APK`.

## ملاحظة حول الأصوات
الأصوات الحالية مؤثرات محيطية اصطناعية مولّدة برمجياً وليست تسجيلات طبيعية احترافية. يمكن استبدال ملفات WAV لاحقاً بتسجيلات مناسبة مع الاحتفاظ بأسماء الملفات.

## المتطلبات
- Android 8.0 (API 26) أو أحدث.
- اتصال إنترنت أثناء أول بناء لتنزيل أدوات Gradle ومكتبات Android؛ تشغيل التطبيق نفسه دون إنترنت.
