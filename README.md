# Dream Sounds 🌙

تطبيق Android عربي لأصوات الطبيعة الحقيقية، مع مزج عدة أصوات، تحكم مستقل بمستوى الصوت، تشغيل في الخلفية، مؤقت نوم، وحفظ الخلطة.

## التسجيلات الحقيقية المتوفرة حالياً
مصدر التسجيلات: حزمة **Park ambiences** للمؤلف Thimras على OpenGameArt، منشورة بترخيص **CC0**:
- طيور الحديقة: تسجيل ميداني لأصوات الطيور قبل المطر.
- النهر والضفادع: تسجيل نهر صغير مع طيور وضفادع وحياة برية.
- رياح الحقول: تسجيل ميداني للرياح في حقل مفتوح.

صفحة المصدر والترخيص: https://opengameart.org/content/park-ambiences

تُنزّل ملفات WAV الأصلية عند أول تشغيل لكل صوت وتُخزّن داخل التطبيق، ثم يمكن تشغيلها دون إنترنت. أحجام التسجيلات الأصلية كبيرة نسبياً؛ يلزم اتصال إنترنت ومساحة تخزين كافية عند التنزيل الأول.

## الميزات
- مزج التسجيلات الثلاثة في الوقت نفسه.
- مستوى صوت مستقل لكل تسجيل.
- تشغيل خلفي عبر Foreground Service.
- مؤقت نوم مع خفض تدريجي في آخر 30 ثانية.
- حفظ واستعادة آخر خلطة.
- جدولة تشغيل يومي.

## البناء
يتطلب JDK 17 وAndroid SDK 35. من جذر المشروع:
`gradle --no-daemon assembleDebug`

## الشفافية
هذه النسخة تستبدل المؤثرات المولدة برمجياً بثلاثة تسجيلات ميدانية موثقة. أصوات البومة وصراصير الليل والمطر والبحر لم تُضف بعد؛ لن تظهر في الواجهة حتى تتوفر ملفات أصلية مباشرة مع ترخيص إعادة توزيع واضح.
