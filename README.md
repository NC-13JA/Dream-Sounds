# Dream Sounds 🌙

تطبيق Android عربي لتشغيل تسجيلات الطبيعة الحقيقية، مع مزج متعدد، تحكم مستقل بالصوت، تشغيل في الخلفية، مؤقت نوم، وحفظ الخلطة.

## التسجيلات الميدانية الحقيقية
- **طيور الحديقة، النهر والضفادع، رياح الحقول:** حزمة Park ambiences للمؤلف Thimras، تسجيلات ميدانية في Adelaide، ترخيص CC0. https://opengameart.org/content/park-ambiences
- **أمواج الشاطئ:** تسجيل jasinski، ترخيص CC0. https://opengameart.org/content/beach-ocean-waves
- **صراصير الليل:** تسجيل حقيقي من حديقة منزلية بواسطة syncopika، ترخيص CC0. https://opengameart.org/content/cricket-sounds
- **المطر:** تسجيل loopable من نافذة منزلية بواسطة Ylmir، ترخيص CC0. https://opengameart.org/content/rain-loopable

تُحمّل الملفات عند أول تشغيل للصوت وتُحفظ داخل مساحة التطبيق، ثم تعمل دون إنترنت. بعض تسجيلات الحديقة كبيرة الحجم وقد تتطلب اتصالاً جيداً ومساحة تخزين كافية.

## الميزات
- مزج التسجيلات الستة في الوقت نفسه.
- تحكم مستقل بمستوى صوت كل تسجيل.
- تشغيل خلفي عبر Foreground Service.
- مؤقت نوم مع خفض تدريجي للصوت.
- حفظ واستعادة آخر خلطة.
- جدولة تشغيل يومي.

## البناء
JDK 17 وAndroid SDK 35:
`gradle --no-daemon assembleDebug`

## الشفافية
كل الأصوات المعروضة في هذه النسخة ملفات صوتية منشورة كمصادر أصلية بترخيص CC0، وليست أصواتاً اصطناعية مولدة برمجياً. لم يُضف صوت البومة بعد لعدم توفر ملف طويل مناسب برابط تنزيل مباشر موثوق ضمن المصادر التي تم التحقق منها.
